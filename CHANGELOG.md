# Changelog

## v1.0.0

Initial public release.

### Features

- Fast native macOS modifier detection
- Supports `cmd`, `opt`, `ctrl`, `shift`, and `fn`
- `!mod` required-off modifiers
- `+mod` exclusive-on mode
- `-h` / `--help`
- `-V` / `--version`
- no-arg mask output
- `--mask` raw exit-code mask
